# Active evidence

This tree contains only machine contracts, fixtures, reference measurements, active gate records,
and the minimum accepted foundation/model evidence required by the Serverless V2 roadmap.

Retained acceptance evidence is limited to:

- the accepted renderer zoom profile;
- the word-transcript, deterministic scheduler, and provider-free orchestration foundations;
- the exact retained Mage and SoulX artifact/runtime qualifications and SoulX composition samples.

Names such as `VF-9-*` or `cp06` inside retained paths, hashes, and immutable image identifiers are
provenance bytes, not current checkpoint selectors or reusable authority. Only
`CURRENT_STATE.yaml`, `MANIFEST.yaml`, and the V2 task briefs select work. Removed checkpoint and
attempt history remains recoverable from Git history and must not be restored into active context.
