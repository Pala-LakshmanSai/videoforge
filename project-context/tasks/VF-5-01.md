# VF-5-01 — Avatar fixture job boundary

Status: exact provider-free implementation brief; dependency-ready after VF-REL-01

## Goal

Define and prove provider-free Avatar worker jobs from exact revision-pinned source assets and
materialized padded span WAVs, including deterministic result validation and lineage.

## Context read profile

Use `phase5_avatar_fixture_jobs` from `MANIFEST.yaml`.

## In scope

- Add canonical Python-side fixture job handling for exact Avatar Profile/version/hash, runtime
  source checksum, selected span-audio checksum, layout, crop/rate profile, task/attempt, and callback
  identity already present in the worker envelope.
- Produce deterministic one-clip results for `AVATAR_FULL` and `AVATAR_SPLIT_IMAGE`; validate media
  signature, duration/frame cadence, dimensions/crop, audio binding, checksum, and technical facts.
- Add fixture success/rejection/retry/cost/review-classification records and deterministic tests for
  tampering, wrong source/span/layout, duplicate callback, cancellation, and workspace isolation.
- Preserve the exact worker shell-argument and callback safety boundary.

## Out of scope

- No AvatarForcing weights/code/download/inference, real generated face/body video, provider call,
  credentials, shared schema/migration, TypeScript route/UI composition, GPU/RunPod/cloud, or spend.

## Ownership

- Lane owns new files under `workers/avatar-fixture/**` only.
- Integration owner owns shared contracts/envelopes, manifests/lockfiles, root files, docs/context,
  TypeScript composition, and any pre-existing file.

## Acceptance

- Focused Python tests prove deterministic bytes/facts, exact lineage, fail-closed validation,
  replay/cancellation behavior, and zero outbound activity.
- Worker lint/tests and forced full `pnpm verify` pass with zero skips at `$0`.
- Evidence: `evidence/acceptance/VF-5-01/avatar-fixture-job-boundary`.

- Roll back with normal Git revert; no external cleanup exists.
