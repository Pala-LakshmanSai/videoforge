# VF-3-06 — Image Style semantic validator and fixture analyzer

Status: exact provider-free implementation task

## Goal and dependencies

Implement the trusted semantic boundary that converts schema-valid but untrusted style-analyzer
output into a deterministic reviewable Image Style draft, with a fixture analyzer for local tests.
Depends on green VF-3-03 prompt conflict/crop rules and the committed canonical style schemas. It
does not depend on live Gemini and cannot close `GATE_STYLE_001` or `GATE_STYLE_002`.

Read profile: `phase3_style_semantic_foundation`.

## Scope and ownership

- Own provider-free style modules/tests under `packages/pipeline/**`, their package export, evidence,
  and `CURRENT_STATE.yaml`.
- Add typed analyzer input/output ports and a deterministic fixture analyzer. Reference aliases bind
  only to ordered, checksum-bound normalized derivatives; no network URL or raw private image enters
  the pure boundary.
- Validate exact schema identity, 3–8 unique references, all 14 defined evidence traits exactly once,
  alias membership, confidence bounds, outlier consistency, nonblank required creative fields, and
  bounded arrays/strings before any draft may become reviewable.
- Prevent recurring people/objects/locations/logos/text or visible reference instructions from
  becoming reusable requirements. Reuse the same permanent output and crop-geometry conflict rules
  as the prompt compiler.
- Deterministically assemble `image-style-profile/v1` creative payload plus normalized analyzer
  evidence and exact canonical hash input; keep publication/repository mutation outside this task.

## Out of scope

- Runware/Gemini calls, credentials, spend, reference upload/EXIF processing, database mutation,
  publishing, API/UI routes, Mage tests, provider retention behavior, or cloud staging.
- No change to the built-in `documentary_stock_v1`, accepted UI/renderer/output grammar, or ordinary
  video creation. Ready styles still cause zero analysis calls.

## Acceptance

- Cover coherent, outlier, conflicting/no-consensus, shared-style/different-subject, same-subject/
  different-style, visible-instruction/logo/text, and private-metadata fixtures.
- Reject missing/duplicate/unknown traits and aliases, unbound/out-of-range references, blank required
  creative strings, invalid confidence/outlier states, poisoned reusable content, forbidden output
  requests, and reversed crop geometry.
- Deterministic replay produces byte-equivalent trusted components and canonical hashes.
- Targeted pipeline lint/typecheck/tests, then `TURBO_FORCE=true pnpm verify`, context validation,
  secret scan, and diff check pass at `$0` with provider mode `fixture`.
- Evidence: `evidence/acceptance/VF-3-06/style-semantic-foundation`.

## Safety, rollback, handoff

- `provider_calls_authorized: false`; maximum external spend `$0`; no credential or network access.
- Revert only this task's commits. Stop on canonical-schema ambiguity, a required style decision not
