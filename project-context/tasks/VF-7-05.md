## Goal

Add one provider-free application service that exposes a safe immutable review snapshot for an
exact VF-7-04 `NEEDS_REVIEW` result and publishes that byte-identical canonical profile only after
an explicit authenticated review decision, with optimistic concurrency and replay safety.

  the actor scope established by the existing authenticated server boundary.
- Return a bounded frozen review snapshot containing the exact canonical profile, profile hash,
  lifecycle/version identity, analyzer request/model provenance, and disclosure actor already

  expected `updated_at`, the exact reviewed hash, the exact stored canonical document, and complete
  accepted VF-7-04 analysis lineage. Re-run canonical schema/hash and deterministic semantic/prompt
  guardrail validation on a plain-data snapshot.
- Publish through the existing atomic repository boundary so the same transaction changes the
  version to `PUBLISHED` and moves only the same parent's `active_version_id`. The prior published
  version remains immutable and historically resolvable.
- Make exact retries return the same result. Reject changed actor-independent inputs, stale
  timestamps, changed hashes/documents/provenance, archived parents, wrong workspaces, non-review
  states, or incomplete accepted analysis lineage without moving the active pointer.
- Add focused fresh/reopened PGlite tests proving safe review reads, exact publication/replay,
  optimistic conflicts, immutable prior versions, active-pointer atomicity, workspace isolation,
  hostile payload rejection, and no ambient I/O.
