# VF-10-11 — V2-11 concurrency, fairness, and resilience

Status: blocked on accepted V2-10; external activation checkpoint

## Goal

Prove two different users can run simultaneously, additional jobs wait fairly, both endpoints scale
0→1→2→0, and faults never cross tenant, authority, output, or cost boundaries.

## Scope

- Exercise 5–10 accounts provider-free, then a bounded live two-user run.
- Test worker death, unhealthy init, capacity delay, unknown ack, duplicate compute, callback loss,
  cancel states, TTL/timeout, partial success, provider errors, DB restart, and object-store delay.
- Measure queue delay separately from init/execution; keep `REQUEST_COUNT=1` and tune only the idle
  window from evidence. Any scaler change requires a new decision and requalification.
- Require one exact combined proposal and fresh numeric user cap before live work.
