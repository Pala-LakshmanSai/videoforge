# VF-4-01 — Durable fixture prompt execution

Status: exact provider-free implementation brief; dependency-ready after VF-REL-01

## Goal

Compose the qualified DeepSeek-shaped prompt writer behind durable task/attempt/outbox execution,
using injected fixture transport only, and persist exact accepted prompt lineage for later image work.

## Context read profile

Use `phase4_durable_prompt_execution` from `MANIFEST.yaml`.

## In scope

- Add a control-plane prompt-execution service that resolves one exact project revision, canonical
  timeline, published style version/hash, and claimed prompt task/attempt.
- Build canonical 25–50 scene batches through the existing compiler/writer ports; default to the
  deterministic fixture writer. A fake qualified-DeepSeek transport may exercise the production-
  shaped adapter without network access.
- Persist exact input/request/response/compiled-output hashes, accepted rows, bounded unresolved-row
  retry lineage, attempt/outbox identity, usage/cost facts, and replay-safe acceptance.
- Fail closed on stale claims, revision/style/timeline drift, malformed or partial output, hash
  mismatch, cost mismatch, conflicting replay, cancellation, or workspace mismatch.
- Add focused fresh/reopened PGlite tests, including zero-outbound-call and telemetry correlation.

## Out of scope

- No image worker/result acceptance, route/UI, new shared wire schema, provider call, credential,
  download, GPU/RunPod, cloud, deployment, or spend.

## Ownership

- Lane owns new `packages/control-plane/src/prompts/**` and focused tests only.
- Integration owner owns shared exports, contracts, migrations, fixtures, root files, docs/context,
  and any pre-existing file.

## Acceptance

- Focused tests prove exact canonical bytes/hashes, restart/replay, bounded retry, cost conservation,
  cancellation/fencing/isolation, telemetry lineage, and zero network activity.
- Control-plane lint/typecheck/build/test, forced full `pnpm verify`, context/schema validation,
  secret scan, Prettier, audit, and diff check pass at `$0`.
- Evidence: `evidence/acceptance/VF-4-01/durable-fixture-prompt-execution`.

## Safety and rollback

- Fixture mode remains default; qualified provider adapters remain runtime-disabled.
- Roll back with normal Git revert; no external cleanup exists.
