# VF-0D-01 — provider sandbox safety harness

Status: authorized provider-free Wave 1 lane

## Goal and dependencies

Build a provider-neutral sandbox harness that proves task/attempt identity, cost reservation,
timeouts, cancellation, evidence hashing, and cleanup verification without reading credentials,
calling a provider, downloading a model, or creating a resource. Depends on committed VF-1-01A
contracts and the Wave 0 context lock.

Read profile: `phase0d_sandbox`. Open gates remain open.

## Scope and ownership

- Own only `packages/provider-sandbox/**` and its isolated tests.
- Define fail-closed sandbox request/evidence interfaces over committed control-plane vocabulary.
- Provide deterministic fake transports for success, timeout, ambiguous acknowledgement,
  cancellation, cap exhaustion, and cleanup failure.
- The integration owner alone edits workspace metadata, lockfiles, schemas, root commands, context,
  or commits.
- Out of scope: credentials, network, provider SDKs, endpoints, model code, GPU resources, pricing
  claims, and gate closure.

## Acceptance

- A missing/disabled authorization envelope rejects before transport execution.
- Every attempt binds exact owner/task/profile/input hashes and an immutable USD sub-cap.
- Reserved, reported, settled, and refunded costs reconcile; retries cannot exceed the task cap.
- Ambiguous acknowledgement requires reconciliation; cleanup failure remains visible.
- `pnpm --filter @videoforge/provider-sandbox lint`, `typecheck`, `test`, and `build` pass.
- Integration runs `TURBO_FORCE=true pnpm verify`, `pnpm audit:dependencies`, and
  `git diff --check` with zero provider calls and `$0` spend.

Evidence: `evidence/acceptance/VF-0D-01/provider-sandbox-harness`.

## Rollback and handoff

Revert the narrow package/integration commits; never weaken control-plane constraints. Record the
task complete without activating `VF-0D-00` or any paid experiment. Provider activation still
requires fresh rates/terms, exact paid briefs, safe credentials, and separate user authority.
