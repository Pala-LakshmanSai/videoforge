# VF-7-07 — Durable Image Style derived-artifact edit service

Status: exact provider-free implementation brief; dependency-ready after VF-7-06 and VF-REL-01

## Goal

Implement the preserve-and-detach manual-edit contract as an authenticated, atomic, provider-free
service before adding API or UI surfaces.

## Context read profile

Use `phase7_style_derived_edit_service` from `MANIFEST.yaml`.

## In scope

- Add the minimum additive migration/repository capability for immutable derived profile artifacts,
  source/derived hashes, server-computed changed JSON pointers, actor/time, expected revision,
  idempotency identity, and current-artifact movement inside one open style version.
- Accept the full candidate `image-style-profile/v1`; validate and JCS-canonicalize server-side.
- Preserve accepted analyzer bytes/evidence unchanged; label them historical source-analysis truth and
  detach confidence/evidence from edited current bytes.
- Atomically invalidate stale review, create the derived link, and move the current pointer. Exact
  replay returns the original result; conflicting replay and stale/partial/cross-workspace writes fail.
- Publishing continues to pin exact current bytes; published versions remain immutable.

## Out of scope

- No Hono route, browser UI, upload/normalization, preview generation, analyzer/provider call,
  credential, cloud/deployment, model/GPU action, or spend.

## Ownership

- Lane owns new style edit service/repository tests in `packages/control-plane/src/styles/**` only.
- Integration owner owns migrations, shared exports/contracts, existing files, root files, and
  docs/context; integration serializes the one migration after lane handoff.

## Acceptance

- Focused fresh/upgrade/reopened PGlite tests cover source preservation, multiple edits, changed
  pointers, stale concurrency, exact/conflicting replay, rollback, publication, post-publication
  rejection, reviewer identity, restore, and truthful historical evidence.
- Control-plane gates and forced full `pnpm verify` pass with zero skips at `$0`.
- Evidence: `evidence/acceptance/VF-7-07/style-derived-edit-service`.

## Safety and rollback

- No accepted analyzer or published artifact may be updated or deleted.
- Roll back additive local changes with normal Git revert; no external cleanup exists.
