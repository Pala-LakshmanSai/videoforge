# VF-8-01 — Node sandbox durable runtime composition

Status: exact implementation successor selected by explicit user direction after VF-3-11 stopped
without a model change

## Goal

Create one restart-safe Node `sandbox` composition over the existing durable PGlite repositories,
local artifact store/workflow, provider-free workers, and accepted web/API surfaces. Replace the
current fail-closed placeholder with a real bounded application runtime without changing production
models, schemas, output grammar, or accepted UI.

## Context read profile

Use `phase8_node_sandbox_runtime` from `MANIFEST.yaml`.

## In scope

- Add an explicit Node-only sandbox application factory and typed durable bindings.
- Reuse committed migrations/repositories, local artifact store, local workflow, fixture prompt/image/
  Avatar writers, timing/timeline services, and FFmpeg v3; do not fork domain logic.
- Persist sandbox state and artifacts under one explicit workspace-local data root.
- Prove restart/reopen, idempotent replay, cancellation, exact hashes, cost truth, and fail-closed
  configuration with focused tests.
- Keep fixture/local modes unchanged and keep provider calls disabled in this task.

## Out of scope

- No model change, weight download, RunPod/GPU/cloud resource, live provider call, credential read,
  deployment, production binding, schema redesign, UI redesign, renderer change, or spend.
- No Neon/R2/Better Auth/Cloudflare Workflow implementation and no refactor of the large PGlite
  adapter except a reproduced blocking defect.

## Acceptance

- A Node sandbox survives a fresh process over the same explicit data root and reproduces exact
  project/revision/task/artifact/timeline state.
- The installed application can complete the existing owned short-video path through FFmpeg v3 and
  checksum-matched download using durable state.
- Missing/invalid bindings fail before work; fixture and local runtime tests remain green.
- Focused tests, `pnpm verify:fast`, context/schema validation, secret scan, dependency audit,
  Prettier, and `git diff --check` pass at `$0` with the server stopped at handoff.
- Evidence: `evidence/acceptance/VF-8-01/node-sandbox-runtime`.
