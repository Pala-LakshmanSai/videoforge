# VF-1-02 — runtime-neutral Hono and local Cloudflare bindings

Status: authorized provider-free Wave 1 integration task

## Goal and dependencies

Make the Hono application factory platform-neutral and add local Cloudflare Vite/Worker emulator
bindings while preserving fixture/local behavior at `http://localhost:4173`. Depends on the green
VF-1-01A handoff and Wave 0 context lock.

Read profile: `phase1_runtime`. Decisions `DEC_HOSTING_001`, `DEC_DB_001`, and `DEC_UX_001` are
fixed; no provider gate is required.

## Scope and ownership

- Integration lane owns the application factory, Node/Cloudflare entrypoints, configuration,
  package metadata/lockfile, route composition, context, evidence, and commits.
- A verification lane may own only new runtime-parity tests after the factory interface commits.
- VF-0D-01 owns only `packages/provider-sandbox/**` in parallel.
- `createApiApp` receives explicit commit, environment, provider mode, and runtime bindings. Core
  application code must not read `process.env`; entrypoints perform translation.
- Support fail-closed `fixture | local | sandbox | staging | production` modes. Only fixture/local
  are runnable in this task; missing bindings for other modes reject at startup.
- Preserve all routes, response shapes, accepted UI, strict port, and local media runner behavior.
- Out of scope: Cloudflare/Neon/R2 account mutation, deployment, OAuth, durable adapters,
  credentials, providers, model downloads, LAN/public listeners, and spend.

## Acceptance

- Node fixture/local and local Cloudflare-emulated fixture requests have response parity for health,
  access, projects, presets, upload validation, idempotency, review, and errors.
- Importing the Worker entrypoint has no Node-server/process dependency.
- Production-like modes fail before serving when required bindings are absent.
- `pnpm dev` still owns `127.0.0.1:4173`; `pnpm dev:status` reports fixture, synthetic, no provider
  calls, `$0`, and matching HEAD.
- Targeted web lint/typecheck/tests/build pass, followed by `TURBO_FORCE=true pnpm verify`, context
  validation, secret scan, dependency audit, and `git diff --check`.

Evidence: `evidence/acceptance/VF-1-02/runtime-neutral-hono`.

fallback. After VF-1-02 and VF-0D-01 are both green, activate the recorded Wave 2 ownership for
VF-1-03, VF-1-04, and VF-1-05. Do not deploy or create a remote.
