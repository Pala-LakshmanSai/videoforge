Implement deterministic scheduled metadata export and a clean-database restore smoke before any
real worker is called production-capable. VF-1-06 must be green and the migration chain frozen for
the export run.

Read profile: `phase1_restore`.

## Scope and ownership

- Own backup/export/restore modules, isolated tests, and evidence only.
- Export schema ledger, identities/memberships, presets/revisions, assets, tasks/attempts, events,
  costs, outbox/workflow records, manifests, hashes, and retention metadata without secret bytes.

  reordered, incompatible, or tampered exports.
- Integration owner alone edits root scripts, migrations, dependencies, context, or commits.
- Out of scope: Neon backup APIs, cloud storage, production schedules, private media export,
  credentials, providers, and spend.

- Tamper/version/partial failures leave the destination clean and explain recovery.
- Post-restore canonical repository and mock-recovery suites pass.
- Owned lint/typecheck/tests pass; integration runs db check, full uncached verify, secret scan,
  dependency audit, and diff check.
