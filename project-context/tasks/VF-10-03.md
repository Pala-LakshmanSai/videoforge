# VF-10-03 — V2-03 fair two-slot admission

Status: blocked on accepted V2-02; provider-free

## Goal

Implement a durable fair queue with at most one active provider workload per account and two active
workloads globally from different accounts. For ordinary production this preserves at most one
active video/account and two active videos globally.

## Scope

- Add atomic account lock, global capacity lease, stable account-local ordering, deterministic
  account rotation, and owned waiter reorder/cancel that cannot change cross-account turns.
- Add explicit tenant-owned Mage/SoulX preset-preview requests on the same slots/account lock; they
  are eligible only after all video heads and never change the video fairness cursor.
- Keep waiting work provider-inert; implement owned cancel/retry and restart-safe slot reclamation.
- Remove normal per-project GPU and Pod lifecycle choices while preserving the UI design.
- Prove 5–10-account contention, no third slot, no same-account double activation, preview/video
  priority, cancellation, crash/restart, and two-user Chrome state.

No Serverless dispatch or external provider action belongs here.
