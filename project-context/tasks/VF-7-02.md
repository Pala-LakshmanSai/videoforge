## In scope

- Add migration `0008_image_style_reference_contract.sql`. It must fail closed if legacy reference
  rows exist rather than inventing rights or source facts, rename the existing ambiguous `asset_id`
  to `normalized_asset_id`, and add required `original_asset_id`, `rights_basis`, optional
  `rights_basis_note`, `rights_attested_at`, and `original_retention_policy` fields.
- Allow rights bases only `OWNED | LICENSED | PUBLIC_DOMAIN | OTHER_DOCUMENTED_BASIS`; require a
  trimmed note only for `OTHER_DOCUMENTED_BASIS`. Allow original-retention policy only
  `RETAIN | DELETE_AFTER_ANALYSIS`. Preserve the existing retention state for later deletion work.
- Add workspace-safe FKs/checks/indexes that keep original and normalized assets distinct, prevent
  one artifact from occupying multiple positions in one version, and preserve order `1..12`.
- Extend the Image Style repository with exact reference attach, resolve, ordered list, pre-analysis
  detach, and deterministic analysis-reference-set resolution.
- Attach only while the version is `DRAFT`, before any analysis attempt exists. Require the rights
  attester to be the current actor and both artifacts to be exact same-workspace verified/accepted
  raster assets: original kind `STYLE_REFERENCE_ORIGINAL`, normalized kind
  `STYLE_REFERENCE_NORMALIZED`, JPEG/PNG/WebP, checksum/bytes/dimensions present, `512..16384` per
  dimension, and at most `20 MiB` each.
- Detach only while still `DRAFT` and before any analysis attempt. Mutation receipt replay must
  return the same detached record. Artifacts remain independently retained; this operation deletes
  only the never-analyzed binding.
- Permit `1..12` draft references. Resolve analysis input only for a contiguous ordered set of
  `3..8`, with deterministic aliases `ref_01..ref_N`, unique normalized hashes, and the exact
  normalized checksum/MIME/dimensions/byte facts required by `buildStyleAnalyzerRequest`.
- Make `beginAnalysis` fail before reservation/state mutation unless that exact valid reference set
  exists. Keep the set immutable after any attempt, including after `FAILED`; retry reuses it, while
  changing references requires abandonment plus a new version.
- Add focused migration/repository tests for fresh and seven-migration upgrade, workspace isolation,
  artifact kind/state/media bounds, rights and retention validation, count/order/hash rules,
  attach/detach replay and conflicts, analysis preflight rollback, post-attempt immutability, and
  reopen/metadata restore.
