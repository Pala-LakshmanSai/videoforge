# VF-7-08 — Versioned Image Style edit API

Status: exact provider-free continuation selected after VF-5-02 completion

## Goal

Expose the completed VF-7-07 immutable derived-edit service through one authenticated, versioned
HTTP mutation using shared contract DTOs. Accept only a complete `image-style-profile/v1`
candidate with exact optimistic and idempotency authority.

## Context read profile

Use `phase7_style_edit_api` from `MANIFEST.yaml`.

## In scope

- Move shared Image Style edit request/response/problem DTOs and runtime validation to versioned
  `@videoforge/contracts` exports; server and clients import that single authority.
- Implement `PATCH /api/v1/image-styles/{style_id}/versions/{version_id}`.
- Require authenticated workspace/actor scope, `If-Match`, and `Idempotency-Key`; reject partial or
  merge patches, unknown fields, malformed candidates, and client-supplied actor/workspace truth.
- Pass the full normalized candidate to the production PGlite VF-7-07 service and return exact
  current artifact/hash/revision/provenance facts.
- Preserve exact replay; reject changed-key reuse, stale revision, wrong workspace/style/version,
  built-in/published/abandoned/non-review state, lineage drift, and storage failure without partial
  mutation.
- Add contract, route, auth, fresh/reopen, concurrency, replay, error-mapping, and zero-outbound tests.

## Out of scope

- No upload/normalization flow, Style Hub UI, preview, browser journey, project selection change,
  live Gemini orchestration, provider call, credential, GPU/RunPod, cloud, deployment, push, or spend.
- No migration or reinterpretation of accepted analyzer/root/derived artifacts unless a reproduced
  schema defect makes an additive migration unavoidable; stop and reconcile before expanding scope.

## Ownership

- One integration owner owns shared contracts, route/server composition, tests, evidence, and
  context. Contracts, routes, lockfiles, and context remain serial.

## Acceptance

- Focused contract/server/PGlite tests prove full-candidate validation, authentication, optimistic
  concurrency, exact/conflicting replay, isolation, immutable lineage, rollback, and reopen.
- Forced full `pnpm verify` passes with zero skips in fixture mode at `$0`.
- Evidence: `evidence/acceptance/VF-7-08/style-edit-api`.
- On completion author exactly one successor brief: `VF-7-09`. Do not author later briefs.

## Safety and rollback

- Preserve accepted root and derived bytes. The API may only invoke the existing atomic edit
  service; it never mutates a published version or project pin.
- Roll back local changes with normal Git revert; no external cleanup exists.
