## Proposed values and approved targets awaiting evidence

- Initial Serverless endpoints use RTX 4090 only. RTX 5090 requires separate exact Mage and SoulX
  compatibility/quality/speed/cost evidence before either lane adds it; no automatic fallback is active.
- The 30-minute all-variable per-video target is ≤$1 and the hard MVP ceiling is ≤$2 under
  `DEC_COST_001`; use representative Serverless cold/warm/concurrent measurements before production.
- Endpoint cold start must remain below RunPod's documented seven-minute unhealthy threshold. Exact
  request TTL, execution timeout, idle timeout, scaling policy, and `RUNPOD_INIT_TIMEOUT` remain
  measured checkpoint outputs, not inherited defaults.
- Storage retention: intermediates 3–7 days, final 30 days.
- Mage output resolution is fixed at 1280×720 by `DEC_IMAGE_001`; visible 1080p delivery quality remains an open acceptance measurement.
- Style analyzer first-attempt target: <$0.08; total with one approved retry <$0.15.
- Per-profile SoulX compatibility preview remains optional until production evidence changes the
  policy. A ready untested/stale profile shows a warning; it never triggers an automatic provider job.

Follow the authority/consistency protocol in `16_CONTEXT_MAINTENANCE.md`; never treat the MANIFEST mirror or an older summary as a separate authority.
