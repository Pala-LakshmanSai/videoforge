# `@videoforge/contracts`

Cross-language boundary validation for VideoForge. The versioned JSON Schemas in
`project-context/evidence/` remain canonical; this package never edits them.

- `pnpm sync` copies the canonical schemas and golden fixtures into `generated/` and
  regenerates the embedded TypeScript/Python schema documents.
- `pnpm sync:check` is read-only and fails when any generated byte has drifted.
- The TypeScript entry point exports strict Ajv validators, Ajv-backed Zod wrappers, and a
  fully typed `createProjectRequestSchema`.
- The Python package exports Draft 2020-12 validators, Pydantic v2 document wrappers, and a
  typed `CreateProjectRequest` model.

The Python package is pinned to the repository's Python 3.12 worker/CI baseline. Install its
isolated test environment once with `pnpm python:install`; subsequent `pnpm test` runs are
network-free.
